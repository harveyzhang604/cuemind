# CueMind · 视频精读与复听

把 YouTube 和 Bilibili 视频变成可以逐句阅读、双语学习、精准复听和保存笔记的资料。CueMind 是 Manifest V3 桌面 Chrome 扩展，使用自己的模型账号和 API Key，没有开发者服务器或遥测。

[English](README.en.md) · [隐私与数据流](PRIVACY.md) · [安全说明](SECURITY.md) · [更新记录](CHANGELOG.md) · [故障排查](docs/TROUBLESHOOTING.md)

## 先看字幕，需要时再配置模型

| 功能 | 是否需要服务 Key |
| --- | --- |
| 平台原文字幕、搜索、逐句复听、保存原文笔记、导出 | 不需要 |
| 字幕翻译、选词解释、视频问答、章节、学习地图、重点词分析、笔记整理 | 用户自己的文本模型 Key；本机模型可不填 Key |
| Supadata 获取 YouTube 已有字幕 | 可选，独立 Supadata Key |
| 无字幕时上传音频或录制标签页转写 | 独立 Whisper-compatible ASR Key |

AI 服务支持 OpenAI、Gemini、DeepSeek 和 OpenAI-compatible 服务，包括本地 Ollama。语音可用 Groq、OpenAI 等带时间戳的兼容接口。服务商的模型、额度与价格可能改变，请查对应官方页面。

**真实 Key 只在本机设置页填写。不要写进代码、环境文件、AI 对话、截图、Issue 或 Git 提交。** 扩展设置存在 `chrome.storage.local`，学习资料存在 IndexedDB；JSON 备份会移除设置里的三项 Key。调用云服务时，Key 会作为鉴权凭据发送给对应服务商，相关字幕、问题或音频也会发送；详见隐私说明。

## 安装

需要桌面 Chrome 116 或更新版本。安装无需 Node.js、Python 或运行构建脚本。

**从源码安装：** 下载或克隆项目到一个固定目录，在 `chrome://extensions` 开启开发者模式，点击“加载已解压的扩展程序”，选择项目里的 `extension/` 文件夹。

**从发行包安装：** 使用当前版本的 `CueMind-v1.0.29.zip`，解压到固定目录，选择里面包含 `manifest.json` 的 `CueMind/` 文件夹。不要选择 ZIP 本身或外层下载目录。`CueMind-source-v1.0.29.zip` 是开发源码包，加载它时选择 `CueMind-source/extension/`。

打开标准 YouTube `/watch` 或 Bilibili `/video` 页面，点击扩展图标或视频里的 CueMind 按钮，再读取视频。平台原文字幕不需要 Key；要翻译或提问时，打开设置页配置服务、地址、模型和自己的 Key。

也可以把这个安装说明交给编码助手：让它下载到你指定的固定目录，指出加载目录并协助验证；**让你自己在设置页输入 Key，助手不要读取或保存真实 Key。**

## 更新与本地数据

将新版文件覆盖到 Chrome 原先加载的目录，再在扩展管理页点击“重新加载”。仍在播放的页面可刷新以重新连接。不要卸载重装，不要每次换目录加载；卸载会丢失本机扩展数据，换目录可能产生不同扩展身份。解压加载不会自动更新。

更新前建议导出完整 JSON 备份。备份有学习内容，不能公开；它不包含设置 Key，换机器后需自己重新填写 Key。新增模型响应缓存不进入备份，跨机器恢复后缺失的中间结果或音频转写可能首次请求服务。

## 主要功能

- 自动读取 YouTube / Bilibili 平台字幕；Bilibili 支持分 P。无字幕时可导入 SRT/VTT，或显式上传音频、录制当前标签页。
- 保留原始字幕、句子 ID 和时间依据，提供完整句阅读、搜索、当前句跟随和连续选句。
- 左右按钮或双按方向键扩大选句范围；空格复听所选范围，再按空格退出复听继续播放。听 1 次、3 次或循环，Esc 停止。输入框中不会劫持文字输入。
- 原文、译文和双语；视频叠加字幕的原文、译文字号独立设置。平台烧录在画面中的字幕无法移除。
- 按考试或行业目标分析三级重点词，自定义术语和已掌握词；字号修改无需模型。目标分析要点击“分析重点词”，各目标分别保存。
- 选词解释、带上下文问答、章节与金句、学习地图、时间戳笔记；相同有效输入优先复用本地结果。
- 复制、Markdown / TXT / SRT / JSON 导出，概览支持大纲和 Mermaid 思维导图。

## 双语翻译、缓存与费用

原文优先读取平台字幕。选择双语或译文后，只要已经配置文本模型且当前记录允许开始任务，插件会自动分批补齐全片译文，优先播放附近；进度中的结果逐步显示并保存。侧栏或视频双语设置均可触发缺失译文处理。取消后保留已完成部分，可以继续补齐。

已有译文、解释、分析和有效模型响应按内容、上下文、模型、服务地址及提示词匹配复用；普通刷新或重开视频不应重复生成完整匹配结果。模型、目标、输入或偏好改变会产生新的结果；主动重新生成、清除缓存、缺失备份缓存也可能产生请求。失败或漏项只补未完成内容。

云模型、ASR、Supadata 可能收费；自动全片翻译和配置模型后的笔记整理也可能收费。请求超时或失败不代表服务商没有计费。请设置服务商额度限制。没有 API 赠送额度，也没有开发者代收费用。

学习数据不会自动过期删除。设置页可以查看各类记录数、内容估算和浏览器存储占用。需要释放空间时先备份，再主动清理：

- 清除分析缓存：清除译文、分析、重点词、问答和模型响应缓存，保留原始字幕、笔记、手动设置与 Key。
- 删除全部笔记：只删除笔记，保留字幕、问答、分析、模型响应缓存和 Key。
- 重置扩展数据：清除全部扩展学习数据、设置及 Key。

本机保存不等于加密密码保险箱；拥有设备或浏览器配置访问权限的人可能读取它们。清理本机不能删除服务商已经收到的数据。

## 支持范围

| 环境 | 状态 |
| --- | --- |
| 桌面 Chrome 116+，标准 YouTube / Bilibili 播放页 | 主要支持与实测环境 |
| Edge 桌面 | 使用相同 Chromium API，但尚未完成独立兼容验收 |
| Firefox、Safari、移动浏览器 | 当前不支持 |
| Shorts、直播、嵌入页、受限或无可用字幕的视频 | 不保证平台读取；标准播放页可尝试导入字幕或音频转写 |

AI 断句和语言分析可能不准确；按真实字幕时间复听不等于逐词音频对齐。重点词表示目标与语境相关性，并非官方考试词表。引用文字一致不保证推理正确。

## 开发与验证

源码没有运行时第三方 JavaScript 依赖。开发需要 Node.js 22+；浏览器夹具测试另需 Python 3.12 和锁定的 Playwright。

```bash
npm ci
npm test
npm run check
npm run format:check
npm run build
```

构建生成安装包、公开源码包、各自的 SHA-256 和文件清单；不依赖系统 zip 命令。检查会拒绝文件白名单外的 Git 文件、符号链接、常见密钥和学习备份。浏览器测试命令、架构和新增文件流程见 [开发说明](docs/DEVELOPMENT.md)。

GitHub Actions 执行公开文件检查、单元测试、格式检查、历史文本密钥扫描、打包和关键浏览器回归。自动检查不证明所有真实视频、网络或付费服务均正常；发布前仍需干净配置的安装、更新及真实视频验收。
