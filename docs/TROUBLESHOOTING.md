# 常见问题 / Troubleshooting

- **加载失败：** 选择含 manifest.json 的目录。源码是 extension/，安装 ZIP 是解压后的 CueMind/。需要桌面 Chrome 116+。
- **更新后设置或 Key 消失：** 确认 Chrome 仍加载原目录、原扩展身份；不要卸载再装或换目录。读取设置失败时先重试，不保存空白覆盖旧设置。
- **无字幕：** 使用标准公开视频播放页，确认平台有可用字幕、Bilibili 分 P 正确。可手动选轨道；YouTube 可配置可选 Supadata native；也可显式导入 SRT/VTT 或转写音频。受限视频、直播和 Shorts 不保证支持。
- **双语只有原文：** 配置文本模型和服务权限，检查翻译进度。双语设置可自动分批补齐全片，译文逐步出现；取消或失败后用“补齐全片译文”继续。不要反复读取视频以重做已完成结果。
- **401/403：** 检查对应文本、ASR 或 Supadata 服务的 Key、账号权限和模型。不同服务的 Key 不可混用。
- **429：** 检查额度、频率限制和服务商状态；不要无限连续重试。超时也可能已计费。
- **Failed to fetch：** 检查网络、所配置服务地址和 Chrome 服务源权限。在设置页重新保存可申请缺失权限，不要把 Key 发给别人排查。
- **咪咕能播放，但 ASR 超时：** 视频、语音识别、翻译分别访问不同服务，不能用“视频能播放”判断 ASR 可达。设置 → 无字幕视频 → 选择“按平台选择”，分别配置 YouTube 和咪咕/B站的供应商与 Key。国内可选豆包语音（需独立 Key 及录音文件极速版权限），文本翻译继续使用 DeepSeek。连接检查仅验证网络，不验证 Key、模型或识别质量；它不上传音频、不修改代理。全局代理仍可能影响国内服务，需让视频与所选 ASR 同时可达。
- **音频采集慢：** 当前从实际播放音频采集，首段约 10 秒，后续约 1 分钟，之后另需 ASR 与翻译时间；不是从片源提前下载整段。每段显示采集大小、电平和请求等待时间。豆包接口需要 WAV，扩展会在本机转换，不能直接把 WebM 发过去。
- **已完成内容又在处理：** 查看任务类型；译文、重点词、概览是不同任务。模型、目标或提示词变化、主动重新生成、清理缓存、跨机恢复缺失响应缓存会需要新请求。普通刷新不会故意清缓存。
- **复听/空格不符合预期：** 输入框中空格用于输入。选好字幕范围后在字幕界面按空格复听；再按空格退出复听继续播放。左右按钮或双按方向键扩大范围，单按方向键跳转 5 秒，Esc 停止。
- **字幕不跟随：** 手动阅读、搜索或选词会暂停自动跟随，点击“当前句”恢复。解释弹窗打开时背景锁定，关闭后恢复。
- **重点词恢复普通字号：** 确认当前视频、目标、原文和偏好匹配；未分析目标为普通字号。先查看完成批次，只重试未完成部分。字号设置本身不调用模型。
- **本地空间不足：** 设置页“查看本地空间”，先导出私人备份，再主动清理分析缓存。清理后缺失结果可能需要重新生成；笔记和原文默认保留。不要直接删除浏览器配置目录。
