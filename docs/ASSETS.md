# Assets and attribution

`docs/assets/demo.svg` is an original vector interface illustration using synthetic learning text, created for CueMind's public documentation. It contains no user browsing profile, account, key or private learning data and is covered by the project MIT license. It is an illustration, not a live-test screenshot.

The extension's three existing PNG icons represent the CueMind C mark. Their original editable generator was not retained in this workspace. They are retained for continuity; this release does not claim a recovered historical source file. `docs/assets/mark.svg` provides an original editable C mark for future exports; it does not assert pixel identity with the historical PNGs.

Private live acceptance screenshots, downloaded video frames and the original requirements DOCX are outside the public file list. Public demonstrations should use synthetic or expressly licensed content. Third-party code notices remain in [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md).
