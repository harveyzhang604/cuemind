无字幕视频 · 语音转写

ASR 将音频转成原文字幕，DeepSeek 等文本模型负责翻译。两者的 Key 分别配置，不能混用。所有 Key 只保存在当前浏览器。

通用 / YouTube 语音服务

支持阿里千问同步 Flash、豆包语音及带时间戳 verbose_json 的 Whisper-compatible 接口。扩展只采集当前标签页播放的音频，按 1× 实时播放以对齐时间戳；首段约 10 秒，后续每段约 1 分钟，随播放进度持续识别。每段状态和失败原因会显示在字幕侧栏；结束采集后会处理剩余音频。也可上传 24 MB 内的音频。

用于将音频转成带时间戳的字幕。获取 Groq API Key ↗，或获取 OpenAI API Key ↗，或获取阿里云百炼 API Key ↗，或获取豆包语音 API Key ↗；请与上方 ASR 地址及模型匹配。

咪咕 / B 站语音服务

选择在视频正常播放时也能访问的服务。千问同步 Flash 直接接收本机采集的音频；推荐 3.1 版以获取完整分句时间戳。3.0 版缺少完整句子时会提示失败，不会保存残缺字幕。 filetrans 系列需要公网音频地址及异步任务，不适用于这里的直接上传流程。扩展不会改变系统代理。

获取阿里云百炼 API Key ↗，或 获取豆包语音 API Key ↗。该 Key 与 DeepSeek、Groq、OpenAI Key 相互独立。

字幕服务

默认直接读取 YouTube / Bilibili 字幕，无需额外 Key。Supadata 是可选的 YouTube 字幕获取服务，与文本模型 Key 独立。

用于获取带时间戳的 YouTube 字幕。创建 Supadata 账号并获取 API Key ↗。

使用时将视频链接和原文语言发送给 Supadata，只请求已有字幕（native），不自动生成 AI 字幕。服务可能计费；官方说明。Bilibili 仍直接读取。
